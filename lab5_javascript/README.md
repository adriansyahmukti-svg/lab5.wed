## File Praktikum
- `index.html`: halaman HTML yang berisi bagian latihan dan mini project.
- `script.js`: kode JavaScript untuk latihan 1–8, mini project, dan eksperimen mandiri.

## Isi Praktikum
1. Menampilkan output pada halaman dan Console.
2. Menggunakan `alert()` dan `prompt()`.
3. Function dan operasi aritmetika.
4. Seleksi kondisi `if–else`.
5. Seleksi kondisi `switch`.
6. Form pemeriksaan bilangan genap atau ganjil.
7. Mengubah warna latar halaman.
8. Checkbox menu makanan dan perhitungan total harga.
9. Mini project kalkulator nilai mahasiswa dengan bobot tugas 30%, UTS 30%, dan UAS 40%, validasi nilai 0–100, predikat, dan status kelulusan.
10. Eksperimen mandiri: operasi dua bilangan dari prompt, tabel perkalian 7, fungsi `cekGenap()`, dan tombol sembunyikan/tampilkan pesan.

## Cara Menjalankan
1. Buka folder `lab5_javascript` di Visual Studio Code.
2. Pastikan `index.html` dan `script.js` berada dalam folder yang sama.
3. Jalankan `index.html` di browser atau menggunakan Live Server.
4. Tekan tombol latihan untuk menjalankan program.
5. Untuk melihat `console.log()`, tekan `F12` dan pilih tab **Console**.
